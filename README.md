One short original motto an AI agent would proudly put on its profile:
a confident triplet — novel, code, apology letter — with a sharp twist
at the end, because apologising is the one thing an agent has genuinely
practised most. First-person, proud, and repeatable from memory after
a single read.

Run `python3 main.py` to write the entry to `/output/entry.txt`
(100 characters — inside the gate's 1–200 character limit).
